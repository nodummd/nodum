## Sharing a note

The share icon at the top-right of a note makes a public read-only link to that note. Anyone with the link can read it — no account needed. Turn it off from the same place.

![The share dialog for a note.](/docs/share.png)

## Publishing a vault

Settings → Publish turns the whole vault into a browsable site under your own slug: every note, with navigation, wikilinks that work between pages, and a link back to nothing private. Unpublish from the same place; the site goes away immediately.
